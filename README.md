CodeAlpha Tasks - Python Internship
Task 1: To-Do List Application.
Description:
A To-Do List application is a useful project that helps users manage and organize their tasks efficiently. This project aims to create a command-line or GUI-based application using Python, allowing users to create, update, and track their to-do lists.
Features:
Task Management: Add, edit, delete and mark tasks as complete. 
User-Friendly Interface: Simple command-line / GUI for easy interaction.
Persistent Storage: Saves tasks for future tracking.
Organization: Helps users prioritize and manage daily tasks effectively.

Task 2: Simple Calculator.
Description:
A basic Python calculator that performs everyday arithmetic operations. The user enters two numbers and picks an operator, the program then calculates and displays the result.
Features:
Basic Operations: Supports addition (+), subtraction (-), multiplication (*), division (/).
User Input: Prompt the user to input two numbers and an operation choice. 
Error Handling: Handles invalid inputs and division by zero. 
Instant Result: Displays the calculated result immediately.

Task 3: Password Generator.
Description:
A password generator is a useful tool that generates strong and random passwords for users. This project aims to create a password generator application using Python, allowing users to specify the length and complexity of the password.
Features:
User Input: Prompt the user to specify the desired length of the password.
Custom Complexity: Option to include letters, numbers, and special characters.
Generate Password: Use a combination of random characters to generate a password of the specified length. 
Display the Password: Print the generated strong password on the screen.
