# CODESOFT - Python Internship Projects

**CodeAlpha Python Internship**

A collection of three beginner-friendly Python projects designed to build fundamental programming skills.

## 📋 Projects Overview

| Project | Description |
|---------|-------------|
| **Task 1: To-Do List** | Manage and organize tasks with persistent storage |
| **Task 2: Calculator** | Perform basic arithmetic operations with error handling |
| **Task 3: Password Generator** | Generate strong, random passwords with custom complexity |

## 🛠️ Tech Stack

- **Language:** Python
- **Development Environment:** VS Code
- **Type:** Command-line & GUI Applications

---

## 📦 Project Details

### Task 1: To-Do List Application

**Description:**
A To-Do List application that helps users manage and organize their tasks efficiently. This project provides a command-line or GUI-based interface using Python, enabling effective task management.

**Features:**
- ✅ Task Management: Add, edit, delete, and mark tasks as complete
- 🎨 User-Friendly Interface: Simple command-line/GUI for easy interaction
- 💾 Persistent Storage: Saves tasks for future tracking
- 📊 Organization: Helps users prioritize and manage daily tasks effectively

---

### Task 2: Simple Calculator

**Description:**
A basic Python calculator that performs everyday arithmetic operations. Users enter two numbers and select an operator, and the program calculates and displays the result.

**Features:**
- ➕ Basic Operations: Supports addition (+), subtraction (-), multiplication (*), division (/)
- 📝 User Input: Prompts users to input two numbers and an operation choice
- ⚠️ Error Handling: Handles invalid inputs and division by zero gracefully
- ⚡ Instant Result: Displays the calculated result immediately

---

### Task 3: Password Generator

**Description:**
A password generator tool that creates strong and random passwords for users. This application allows users to specify password length and complexity requirements, generating secure passwords instantly.

**Features:**
- 🔐 User Input: Prompt the user to specify the desired length of the password
- 🎯 Custom Complexity: Option to include letters, numbers, and special characters
- 🎲 Generate Password: Uses a combination of random characters to generate a password
- 📋 Display Password: Prints the generated strong password on the screen

## 🚀 Getting Started

### Prerequisites
- Python 3.8 or higher
- VS Code (or any Python IDE)

### Installation

```bash
# Clone the repository
git clone https://github.com/aKIRTIak47/CODESOFT.git

# Navigate to the project directory
cd CODESOFT
```

### How to Run

Each project can be run independently:

```bash
# Task 1: To-Do List
python task1_todo.py

# Task 2: Calculator
python task2_calculator.py

# Task 3: Password Generator
python task3_password_generator.py
```
